「鸿蒙 OS」（HarmonyOS，华为）和「澎湃 OS」（HyperOS，小米）是国产 Android 生态里两个最常见的系统。两者底层架构差异（鸿蒙 NEXT 已经不再基于 AOSP）不在本篇讨论。从隐私角度看，它们和其他国产 ROM 一样，**默认开启**了一批数据收集开关、个性化推荐、推送通道与厂商账号同步。本篇是一份"新机第一天"的快速过滤清单。

## 共同的几个层面

不论鸿蒙还是澎湃，请按这几个层面理解你的隐私边界：

1. **厂商账号**（华为账号 / 小米账号）：是云服务、应用商店、推送、设备查找的总开关。一旦登录，部分数据（设备列表、登录位置、推送 token）就会和账号绑定。
2. **应用商店与推送**：国产手机的推送通道大多由厂商自家服务接管（华为推送服务 / 小米推送服务），即便第三方 APP 用的是自己的服务端，落到设备这一端通常也走厂商通道。
3. **系统遥测**："用户体验改进计划""个性化推荐""智慧服务""场景化推荐"——名字不同，本质都是在收集你的使用行为。
4. **国内版 vs 海外版**：HarmonyOS 海外版（华为部分海外机型）、HyperOS Global（小米海外版）默认收集策略与国内版**不完全一致**，海外版通常不预装中国大陆专属服务。买卖二手机或跨境换机时务必看清楚自己手上的是哪个版本。

## 鸿蒙 OS（HarmonyOS / HarmonyOS NEXT）

进入「设置」，按以下顺序检查：

### 账号与隐私

- 「华为账号」→「隐私中心」：逐项查看"个人信息收集清单""第三方信息共享清单"。
- 「华为账号」→「云空间 / 备份」：决定是否开启云备份；不需要就关闭。
- 「隐私 → 加入用户体验改进计划」：**关闭**。
- 「隐私 → 系统加入广告标识符（OAID）个性化」：**关闭**，并重置 OAID。
- 「隐私 → 应用启动管理」：保持"自动管理"，避免 APP 在后台无限自启。

### 位置与权限

- 「位置信息」：建议设为"使用应用时"。"始终允许"只给真正需要的 APP（如导航）。
- 「定位服务 → Wi-Fi 与蓝牙扫描」：默认开启，会在不连接的情况下也持续扫描；**根据需要关闭**。
- 「权限管理」：逐项检查相机、麦克风、通讯录、短信、通话记录、剪贴板（部分版本独立列出）、附近设备。

### 通知、推送与广告

- 「通知 → 锁屏通知」：不让通知内容直接展示在锁屏上。
- 「华为浏览器 / 应用市场 / 主题」内的"个性化推荐 / 资讯推送"：**全部关闭**。
- 「设置 → 隐私 → 广告」：关闭"个性化广告"、定期重置广告标识符。

### 输入法、剪贴板、无障碍

- 优先使用 **系统自带输入法**，不开"云联想"。详见《[输入法监控](/zh/brochures/input-method-surveillance)》。
- 「无障碍服务」：除非确有需要，**不要给手机管家、清理工具、电商 APP** 开无障碍。
- 「剪贴板访问」：检查哪些 APP 默认能读剪贴板，按需关闭。

## 澎湃 OS（HyperOS / 小米手机）

进入「设置」，按以下顺序检查：

### 账号与隐私

- 「小米账号」→「隐私 / 安全中心」：逐项查看个人信息收集与共享清单。
- 「我的设备 → 备份与恢复 → 小米云」：决定是否启用云备份。
- 「密码与安全 → 隐私保护 → 加入用户体验改进计划 / 性能体验改进 / 体验问题诊断」：**全部关闭**。
- 「密码与安全 → 隐私保护 → 广告服务 / 个性化广告推荐」：**关闭**，并重置广告标识符。

### 位置与权限

- 「位置信息」：设为"仅在使用时"。
- 「位置信息 → 改进位置精度（Wi-Fi 扫描 / 蓝牙扫描）」：**根据需要关闭**。
- 「应用 → 权限管理」：相机、麦克风、通讯录、短信、通话记录、附近设备等逐项检查。

### 通知、推送、内容推荐

- 「通知与控制中心 → 锁屏通知」：建议设为"隐藏内容"或不在锁屏显示。
- 系统应用（浏览器、应用商店、主题、音乐、视频）里**逐个**关闭：
  - 「资讯 / 头条 / 推荐」流
  - 「个性化推送 / 智能推荐」
  - 「相关性推荐 / 兴趣偏好」
- 「应用商店 → 设置 → 应用推荐」：通常默认开启"推荐应用"，可以关掉。

### 桌面与负一屏

- 「桌面设置 → 应用推荐 / 智能助理」：**关闭**。
- 负一屏（向右滑或下拉的"智慧助理 / 智能助理"）的内容卡片：除非真的用，**关闭**。

### MIUI / HyperOS 特有项

- 「特殊权限 → 隐藏应用 / 第二空间」：可作为"高风险用户"在主力机上保留一个干净空间的兜底；但要清楚第二空间的密码也只是 OS 级密码，不是端到端加密。
- 「开发者选项 → USB 调试」：日常用机请关闭。

## 国内版 vs 海外版的差异

- **HarmonyOS / HarmonyOS NEXT 国内版** 默认绑定华为账号、华为应用市场、华为推送、华为云。海外版部分机型仍包含 Google Mobile Services（GMS）有限支持。
- **HyperOS 国内版** 默认绑定小米账号与中国大陆数据中心；HyperOS Global 默认数据存储于其他地区数据中心，并预装 GMS。
- **跨境用户/购买全球版的用户**：注意你的"账号注册地"决定了大量隐私默认值，刷机不会改变账号注册地。

## 普通用户怎么做

按上面的清单走一遍。重点：

- 关掉"用户体验改进 / 体验诊断 / 性能数据"。
- 关掉"个性化广告"、重置广告 ID。
- 关掉系统应用里的"资讯 / 头条 / 推荐"。
- 把无障碍权限收回。
- 锁屏通知不显示具体内容。

## 高风险用户怎么做

- **强烈建议工作机使用 GrapheneOS（在 Pixel 设备上）或一台彻底刷机后不登录任何中国大陆账号的全球版设备**。
- 如果必须使用国行机（例如要用国内移动支付、出示健康/出行码等），**只在生活机上用，工作内容不进这台手机**。
- 跨境出行务必结合《[High-Risk Environments](/brochures/high-risk-environments)》。

## 今天就能做的事

- [ ] 在「隐私 / 安全中心」里关掉**用户体验改进**所有相关项。
- [ ] 关掉**个性化广告**并重置广告 ID。
- [ ] 检查并关掉系统应用（浏览器、应用商店、主题）的**资讯推荐流**。
- [ ] 锁屏通知改为"隐藏内容"。
- [ ] 「位置 → Wi-Fi/蓝牙扫描」按需关闭。

> **底线**：鸿蒙和澎湃的"日常默认值"对个人信息相当宽松。一次性按清单关掉一批不必要的开关，绝大多数普通用户的隐私就已经显著改善。
