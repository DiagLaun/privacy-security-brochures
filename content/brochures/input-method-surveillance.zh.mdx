中国大陆主流的第三方输入法（搜狗、百度、讯飞、QQ）都默认提供「云联想 / 云输入 / 云预测」功能：你打字的过程中，输入法会把你输入的拼音、甚至上下文片段上传到云端，云端返回更"智能"的候选词。**默认情况下，你打的每一句话都会经过别人的服务器**。这是输入法在中国大陆使用的、各家都公开承认的工作机制；但它意味着的隐私边界，很多人没有意识到。

## 它具体在做什么

各家细节略有不同，常见的"云"功能包括：

- **云联想 / 云输入 / 云候选**：把你正在输入的拼音串发送到云端，返回更多候选词。
- **云用户词库 / 云同步**：把你的个人词库（习惯用语、人名、专有名词）同步到云端，方便换设备时还原。
- **个性化推荐**：根据你"经常说什么"训练个人模型——这意味着这些数据要离开设备。
- **「智能纠错 / 滑行输入」**：部分实现需要上下文片段联网。
- **「斗图 / 表情商店 / 资讯流」**：很多输入法的"商店""资讯"模块本身又是一个收集行为数据的入口。

## 关于公开研究

Citizen Lab（多伦多大学）多年来对中文输入法的网络行为做过系统研究，公开报告中曾发现：

- 部分国产输入法（含搜狗早期版本）在传输用户输入时存在 **加密强度不足或可被解密** 的问题，使得键入内容可能被同网络的中间方还原。
- 不同年份的厂商响应不一，部分问题已经得到修复，部分功能（如默认开启的云联想）仍是行业惯例。

具体情况随版本而变，请以各厂商最新版本与最新公开研究为准。**结论性建议是稳定的：把"云联想"默认开启的输入法当作不适合输入敏感内容的工具来对待。**

## 真正的风险点

不是"输入法在偷拍你"。是这些事的组合：

1. **默认开启**：用户没有主动选择，但每一句话都经过厂商服务器。
2. **覆盖面极广**：输入法是所有 APP 都要调用的组件——网银密码、私聊、邮箱、搜索都从这里过。
3. **权限叠加**：在 Android 上，第三方输入法常额外申请「无障碍 / 通知 / 读取剪贴板」权限。一旦授予，能拿到的远超输入本身。
4. **跨设备同步**：「云用户词库」会把你打过的"人名 / 私密用语"长期保留在厂商账户里。

## 普通用户怎么做

把"输入法"当一项需要主动配置的隐私组件来对待：

### iPhone

- 优先使用 **系统自带"简体拼音"输入法**——不上传输入内容到第三方。
- 如果坚持用第三方输入法（例如搜狗、讯飞），需要在「设置 → 通用 → 键盘 → 键盘」里给该输入法授予"完整访问权限"，**才能联网**——不给"完整访问"，第三方输入法的云联想就不能工作；这本身就是一个有用的开关。
- 在密码框里打字时，iOS 会**自动**切回系统键盘，第三方输入法看不到密码框内容。

### Android（鸿蒙、澎湃、ColorOS、MIUI、ColorOS、One UI 国行）

- 进入第三方输入法的设置，关闭：
  - 「云联想 / 云输入 / 云候选」
  - 「用户词库云同步」
  - 「个性化学习 / 个性化推荐」
  - 「输入纠错网络辅助」
  - 「斗图 / 表情 / 资讯 / 商店」相关入口
- 「设置 → 应用 → 输入法 → 权限」：关闭通讯录、短信、定位、相机、麦克风。
- 「设置 → 无障碍」：除非你确实需要无障碍辅助，**取消该输入法的无障碍服务**。
- **在密码框、银行 APP、医疗 APP、政务 APP 中**，如果系统支持"使用安全键盘 / 系统键盘"，请使用——很多此类 APP 自带不联网的安全键盘。

### 跨平台通用建议

- 输入法是所有应用的入口，**装一个就够**，不要装多个。
- 长期不用的输入法直接卸载，而不是仅仅"不当默认"——它在后台仍然能拿到大量信号。

## 高风险用户怎么做

- **不使用任何第三方国产输入法**。系统自带（iOS 简体拼音 / Android 厂商原生 / GBoard 海外版）即可。
- 如果你在工作机上需要输入大量敏感词（比如调查记者整理材料、律师起草文书）：
  - 关闭一切输入法的"网络辅助"。
  - 关闭剪贴板读取权限。
  - 把工作内容尽量用**离线编辑器**（不联网的本地笔记 / 文本编辑器）整理，再粘贴到目标 APP。
- **跨境出行前**清掉输入法的"用户词库"——很多年的"个人词库"本身就是一份你的人际关系图。

## 今天就能做的事

- [ ] 检查你手机上**默认输入法是哪一个**。
- [ ] 进入它的设置，找到「云输入 / 云联想 / 云候选 / 云同步」并**关闭**。
- [ ] 关闭「个性化学习」「个性化推荐」「输入纠错网络辅助」。
- [ ] 关闭它的「斗图 / 表情商店 / 资讯」入口。
- [ ] 「设置 → 无障碍 / 通知访问 / 剪贴板权限」，**收回输入法不该有的权限**。
- [ ] 至少在网银、政务、医疗、私聊场景使用系统自带输入法。

> **底线**：输入法是离你最近的一层"日常上传"。把它换成系统自带或关掉云联想，是单次操作就能拿回来的隐私收益最大的事情之一。
