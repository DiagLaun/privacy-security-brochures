很多关于"反追踪"的方案最后都指向 root / 刷机 / GrapheneOS。问题是真正能做这些的是少数人——大多数普通用户用的是国行手机、国行账号、国产 ROM，从一开始就内置了厂商账号、厂商应用商店、系统级遥测和大量预装 APP。

这一篇就只回答一个问题：**如果你不能 / 不愿 root 或刷机，到底还能做哪些有效的事？**

> **本手册仅讨论数据卫生与减少自身数据暴露。** 不讨论规避网络管制、不讨论对抗合法侦查——后者属于法律 / 个人风险判断，每个人的答案不同，本手册不替你回答。

## 先把"解决不了"的部分讲清楚

**这些事 root 也不能解决：**

- **公共空间摄像头 + 人脸 + 步态识别**：物理空间里的识别和你的手机配置无关。
- **运营商基站定位**：只要你开机插 SIM，你就在被基站记录。这不是 APP 层面的事。
- **支付 / 出行 / 住宿 / 医疗的实名后台数据库**：高铁票、机票、酒店、看病、银行——这些数据流和你的设备配置无关。
- **微信 / 支付宝等"必装 APP"在国内的合规义务**：root 与否，行为是一样的。
- **同伴节点暴露**：你做得再干净，对方家人朋友的设备一拍合影 / 一存通讯录，你又出现在另一个数据点上。

> **"反追踪"不是一个开关，而是一组持续在做的小事。目标不是"消失"，是"不让你成为最低成本的数据来源"。**

## 普通人不 root 也能做的事（按收益排序）

### 1. 设备选型——单项收益最大

收益由高到低：

1. **iPhone + 海外 Apple ID**：最关键的一点是，iCloud 数据**不**进入"云上贵州"（云上贵州只接管中国大陆 Apple ID 的数据）。前提是你能合规获得海外 Apple ID 并按规则使用，且不要混用国行和海外区购买。详见手册的「云上贵州与中国大陆 iCloud」一篇。
2. **iPhone + 国行 Apple ID + 关闭 iCloud 备份/照片/Drive**：次一级方案。系统层数据收集仍受 Apple 默认设置约束，远低于多数国产 ROM。
3. **境外购入 Pixel + 原生 Android**：默认 Google 服务，权限系统比国产 ROM 透明。在大陆使用 Google 账号需要走自己的网络中转，本手册不展开。
4. **国行安卓**（鸿蒙 / 澎湃 / ColorOS / OriginOS / MIUI 等）：默认包含厂商账号 + 厂商应用商店 + 系统级遥测，不 root 几乎无法关闭。这是收益最差的一档——但**仍然可以做下面 2-12 的事**。

> 一句话：**对绝大多数中国大陆普通用户，"换成 iPhone 并使用海外 Apple ID" 是单一动作收益最高的反追踪决策**。

### 2. 账号与身份分层

- **不要把所有事放在同一个账号上**：邮箱、Apple ID、Google 账号、支付账号、社交账号——分开。一个被攻陷不会带塌全部。
- **副卡 / 虚拟号**：国内主流 APP 大多要求实名手机号，但**至少**做到"主号绑银行 / 政务 / 家人，副号注册外卖 / 电商 / 出行"。
- **不同 APP 用不同邮箱别名**：很多邮箱支持 `xxx+douyin@example.com` 这种 plus-address，能识别哪家漏了你的数据。
- **政务类 / 社保 / 银行 APP** 单独装在一台手机或一个用户上，不要和日常娱乐 APP 混用。

### 3. 权限卫生（这一项不 root 完全可以做）

iOS 与 Android 的设置都允许你逐 APP 关闭权限，**绝大多数权限对绝大多数 APP 不是必需的**：

- **通讯录权限**：除了真正需要打电话的 APP（拨号、Signal、WhatsApp），其它一律关。一个外卖 APP 不需要看你 800 个联系人。
- **照片权限**改成"选定的照片"（iOS 14+）/"仅本次允许"（Android 11+）：APP 不需要看你整个相册。
- **定位权限**默认改"使用 APP 时"，关闭"始终允许"，关闭"精确位置"（除非真的需要导航）。
- **"识别附近设备" / 蓝牙**：除了耳机、车机、智能手表的配套 APP，其它一律关——这是新一代被滥用的追踪权限。
- **剪贴板访问**：iOS 默认会提示，注意每次弹窗——很多 APP 一启动就读剪贴板。
- **系统通知读取**：某些"安全管家""清理大师"会要求这个，等于让它读你所有 APP 的通知内容。
- **无障碍服务**：除非你真的用屏幕阅读，无障碍权限可以让 APP 看到屏幕上每一个字、模拟你的每一次点击。任何要求开"无障碍"的非辅助类 APP 都可疑。
- **"自启动"和"关联启动"**：国产 ROM 在系统设置里都有这个开关，比 root 简单得多。

### 4. 云备份——把数据留在自己手里

- **iCloud**：海外区 Apple ID 可以放心开 iCloud 备份；国行账号则建议**关闭** iCloud 备份 / iCloud 照片 / iCloud Drive，改用 Mac/PC 通过 Finder/iTunes 做本地加密备份。
- **小米云 / 华为云 / OPPO 云 / vivo 云**：默认会同步通讯录、短信、相册、通话记录、备忘录。**至少**关闭"通讯录""短信""通话记录""备忘录"四项云同步。
- **百度网盘 / 微云**：不放敏感资料。要放的话先用 Cryptomator（https://cryptomator.org/ ）做客户端加密容器再上传。
- **微信"收藏"**：它不是端到端加密的备份。不要把身份证 / 银行卡照片 / 体检报告放进去。

### 5. 输入法

- **iPhone**：用系统自带的拼音 / 仓颉 / 注音；任何第三方输入法都**不要打开"允许完全访问"**——这个开关不打开，输入法就联不了网。
- **国产 Android**：搜狗 / 百度 / QQ 输入法都默认上传日志。可选：
  - 系统自带输入法（关闭"在线纠错""个性化推荐""用户体验改进计划"）。
  - **GBoard**（需海外 Play 商店或 APK 侧载，关闭"个性化"和"使用统计"后较为安全）。
  - **Trime / 同文输入法**（基于 RIME，开源，本地词库），可在 F-Droid 安装。
- **永远不在敏感对话里使用语音输入**——语音转文字是**云端**完成的。

详见手册的「输入法监控」一篇。

### 6. 浏览器与搜索

- **不要用**：UC、QQ、360、百度、华为浏览器、小米浏览器、夸克——这些默认开启大量数据收集。
- **可以用**：Safari（iOS）、Brave、Firefox（含 Firefox Focus）、Edge（关闭"必应建议"和"诊断数据"）。
- **搜索引擎**：百度 → 必应（默认即可，比百度好不止一档）→ DuckDuckGo / Brave Search（在你的网络下可达时）。

### 7. 网络层（不涉及网络中转）

- **关闭"广告标识符"**：iOS 在"隐私与安全 → 跟踪 → 允许 APP 请求跟踪"里关闭；Android 在"设置 → Google → 广告"里"删除广告 ID"。
- **公共 Wi-Fi 不登录敏感账号**：商场、机场、酒店 Wi-Fi 经常要求"微信登录""手机号 + 验证码"，等于把你的 MAC 地址 + 实名 + 时间地点交出去。
- **私有 MAC 地址（Wi-Fi 随机化）**：iOS 和较新 Android 都默认开启，确认它在每个 Wi-Fi 上都开着。
- **不要装**任何标榜"加速 / 净化 / 反追踪"的 APP——这一类 APP 是问题本身的来源，不是解决方案。

### 8. 双机分层（**对普通人收益最大的非技术性方案**）

- **生活机**：装国家反诈中心、政务、社保、医院 APP、公司钉钉、家人微信群。
- **隐私机**：日常社交、阅读、私密对话。这台机不装上述 APP、不登录上述账号。
- **不需要刷机**——只需要"分开"。这是对绝大多数普通用户最现实、收益最高、零技术门槛的方案。
- 如果只能一台机，至少在这台机上做"账号分层"+ ROM 级别的"应用双开"（区分两个微信、两套联系人）。

### 9. 物理层

- **摄像头贴**（前后摄）：几块钱，挡住时彻底物理可信。
- **锁屏通知改"隐藏内容"**：发件人和正文都不要显示。
- **关闭锁屏 Siri / 语音助手**：避免拿到机就能问"我的快递在哪"。
- **关闭"始终显示"**：某些场合不让屏幕一直亮。
- **离开座位锁屏**：现代手机被人一摸就能解锁、记录、上传。

### 10. 通讯本身

详见手册的「加密通讯 APP 选型」。一句话：**至少和 3 位最在意的家人 / 朋友约一条不在微信和 SMS 上的第二渠道**——出事时它会救你。

### 11. 减法 > 加法

- **删除你不再用的 APP**——它们是被遗忘的数据通道。
- **取消"自动续费"和"开机自启"**——顺手做的减法。
- **把订阅类服务集中到 1-2 家可信厂商**——10 家小厂的隐私政策合起来比 1 家大厂的隐私政策更糟。

### 12. 不要做的事

- **不要 sideload 来源不明的"去广告版" / "破解版" APP**——这些经常携带恶意代码，比原版还糟。
- **不要把所有这些"加固动作"展示出来**——把手机壳改成"反摄像头 LED"、把入门页改成"反追踪"主题，本身就是一个独特识别特征。**低调** > **看起来很硬核**。
- **不要在没有评估的情况下把"反追踪"清单分享在群里**——你以为是隐私话题，对手把它当社工材料。

## 普通用户怎么做

如果只想做一件事：**把双机分层做起来**——一台机装"必装 APP"（国家反诈中心 / 政务 / 公司 / 家人微信群），另一台机做日常隐私和社交。两台机都不刷机也能立刻有效。

如果想做三件事：

1. 双机分层。
2. 给主力机里所有不需要的 APP 关掉通讯录、相册、定位、剪贴板权限。
3. 关闭厂商云的"通讯录 / 短信 / 通话记录"同步。

如果想做"以后也不再多想"：换 iPhone + 海外 Apple ID + 关闭"允许 APP 请求跟踪"。这是单一动作里收益最高的一项。

## 高风险用户怎么做

普通用户清单 **是地基**，但对调查记者、维权律师、参与敏感案件的当事人、跨境工作者来说，仅靠这一篇是**不够**的。请额外阅读：

- 「高风险环境下的应急处置」——三层设备策略、跨境检查、被约谈/搜查的应对
- 「加密通讯 APP 选型」——Signal / Threema / Delta Chat / Zangi 的选型与边界
- 「鸿蒙 OS 与澎湃 OS 隐私设置」——设备级遥测的关闭清单
- 「输入法监控」——为什么这是最容易被忽略的泄露面

## 今天就能做的事

- [ ] 列一份你手机上的 APP 清单，**删掉过去 3 个月没打开过的所有 APP**。
- [ ] 进设置 → 隐私（iOS）/ 权限管理（Android），**给每个还留着的 APP 重新过一遍权限**——通讯录、照片、定位、剪贴板、附近设备、无障碍。
- [ ] 进厂商账号设置，**关闭"通讯录 / 短信 / 通话记录"云同步**。
- [ ] 进系统设置，**关闭"广告标识符"** 与"个性化广告"。
- [ ] 锁屏通知改成"隐藏内容"。
- [ ] 给摄像头贴一张物理贴纸。
- [ ] 找一台旧手机或便宜手机当作"隐私机"——**只装日常社交，不装政务 / 工作 / 家人群相关 APP**。
- [ ] 和 3 位最在意的家人 / 朋友约一条**不在微信 / SMS 上**的第二渠道（参见「加密通讯 APP 选型」）。

> **底线**：在国产 ROM + 全实名 + 公共摄像头普及的环境下，普通人的目标不是"消失"，是"不让你成为最低成本的数据来源"。
>
> 单项收益最大的三件事：(1) **换 iPhone + 海外 Apple ID**（不行的话至少关 iCloud 备份）；(2) **双机分层**——把"装国家反诈中心 / 政务 APP"和"日常隐私"分开放；(3) **逐 APP 关掉它不需要的权限**——尤其是通讯录、定位、相册、无障碍。
>
> 这三件做完，已经把你和系统默认值之间的差距拉开了 80%。剩下 20% 才是 root / 刷机 / GrapheneOS / 自建 DNS 这些技术活。
