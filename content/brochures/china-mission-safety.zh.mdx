> **本手册不讨论是否应当从事相关事工，也不讨论中国大陆的宗教政策**——这些是法律 / 信仰 / 个人良心的判断，每个人答案不同，本手册不替任何人回答。
>
> 它只回答一个问题：**当类似事件发生时，怎么把对自己、对身边的人、对所牧养群体的伤害降到最小？**——这与任何 NGO、外籍专业人员、跨境工作者面对的"高风险环境"威胁建模框架一致。

近年公开报道里反复出现同一类模式：长期在地服侍的外籍宣教士被即时驱逐出境；本地牧者、长老与全职同工被带走；信徒群体被约谈与"家访"。本篇针对这类**模式**，不针对任何单一事件。

## 第一原则：保护网络，不只是保护自己

跨文化宣教 / 家庭教会牧养这一类工作，最敏感的不是"你"，是**你设备里那张关系图**。

- 你手机上一份"小组成员清单"——意味着 30~80 个人和家庭被同时点亮。
- 一段全员合影——在人脸库里就是一组关联节点。
- 一笔国际汇款——在反洗钱系统里是一条永久记录。

这意味着：**对你个人的"安全"，永远不能高于对网络的安全**。如果某项工具更方便但会泄露关系图，就不能用。这是这一类事工和"普通人隐私"最根本的区别。

## 角色不对称：四类人，四种威胁模型

这一类事件里，**承受后果最重的从来不是外籍人员**。建议先把你身边的人按风险分层。

| 角色 | 最坏情形 | 应对重点 |
|---|---|---|
| 外籍宣教士 / 家属 | 拒绝续签 → 限期出境 → 永久不准入境；个别情况下短期拘留 | "随时可走"的预案；离开时不要把本地伙伴的资料带走时一并暴露 |
| 本地牧者 / 长老 | 长期监控、约谈、行政拘留、刑事拘留（"非法经营""扰乱秩序""利用邪教破坏法律实施"等罪名）、家属波及 | 极致的设备和资料卫生；预先安排家庭支持 |
| 本地全职同工 | 与上同，量刑通常较轻，但失去工作、社保连带 | 同上，并避免成为"领头"标识 |
| 普通信徒 | 可能被约谈、签悔过书、被工作单位 / 学校通报 | 不出现在"花名册"里；对外保持低调 |

> **外籍人员的"最坏"通常是中国籍同工的"最好"。**
>
> 在做任何决定时——尤其涉及外联、媒体、对外公开——先问一句："这件事我能承担，但留下的人能不能承担？"

## 设备与账号

- **不在主力机上做事工**。事工设备和生活设备分开——这一项没有讨价还价的空间。参见手册的「普通人的数据卫生清单」「高风险环境下的应急处置」。
- **iPhone + 海外 Apple ID** 最稳。不要让事工资料进入云上贵州。**不**用国行 iCloud 同步事工资料。参见「云上贵州与中国大陆 iCloud」。
- **不**装国家反诈中心、手机管家、国产输入法在事工机上。参见「国家反诈中心 APP」「手机管家 / 安全中心类 APP」「输入法监控」。
- **不**让国产 ROM 的厂商账号同步通讯录、短信、相册。参见「鸿蒙 OS 与澎湃 OS 隐私设置」。
- **不**用同一个微信号同时联系家人和同工。
- **生物识别在路上 / 出境时关闭**——改用 6 位以上 PIN 或口令。
- **二步验证用硬件密钥**（YubiKey / Titan Key），不要短信。
- **退出所有"会议邀请历史"**——Zoom / 腾讯会议的"参会记录"是一份网络图。

## 通讯

- **核心同工之间用 Signal**，**亲自核对安全号码**，默认开"消失消息"。参见「加密通讯 APP 选型」。
- **不**在微信 / QQ 上讨论事工内容、做小组邀请、传播文字资料、转发奉献账号。微信群组的留存能力远超大多数人估计。
- 涉及代祷信息、人事决议、财务等敏感对话——**只用面对面、笔记本会议（不带手机）、或 Signal**。
- **联系人头像、昵称、备注不要写真名 / 真职务 / 真单位**。Signal 的联系人列表本身在设备被检查时即可暴露关系网。
- 跨境联络（与海外母会 / 差派机构）走加密邮件 + PGP，或 Signal。**不**走未加密的工作邮箱。

## 名册、教材、个人资料

这一项往往是最容易出问题的地方。

- **不存储完整成员名单**。如果必须有，分散保存、加密容器（VeraCrypt / Cryptomator）、从不带进事工聚会地点。
- **训练材料数字化 + 加密**。物理纸本只在使用时带、用完即归集中保管在受信任的地方。
- **不在云端搜索栏 / 浏览器收藏夹留下"成员奉献""小组分组""教会同工通讯录"等文件名**——文件名本身就是元数据。
- **照片**：合影、洗礼照、退修会照片——是**最大**的网络暴露源之一。
  - 不发朋友圈、不发到"同工群"。
  - 关闭照片 EXIF 的 GPS（iPhone：相机设置 → 关定位；Android：相机内关位置）。
  - 已存在的合影做"模糊面部"处理或不再传播。
- **讲章 / 备稿** 不放百度网盘、不放 OneDrive 国行版、不放 iCloud Drive 国行账号。要放就放在端到端加密的国际服务（Proton Drive、Tresorit）或加密容器里。

## 资金流

国际汇款 + 宗教用途，是反洗钱与外汇管理两条线交汇处的高敏感行为。

- **不**通过本地银行账户接收"奉献""支持金"等明显标识。
- **不**让境外母会按 "missionary support"、"church donation"、"ministry" 等字段汇款进来。
- 海外薪资 / 支持的合规渠道：通过差派机构 / 第三方 NGO / 商业雇佣关系（带正常工作签证）支付。具体安排请询问你的差派机构与有跨境经验的合规律师，**不要**自行判断。
- **现金流水不能多于你的"职业身份"能解释的范围**——这是被约谈时最常被问的事。
- **不**用支付宝 / 微信支付收"奉献"——这是最快速暴露名册的方式。

## 身份与"职业"分层

许多外籍宣教士同时持商务签证 / 工作签证（英语外教、企业职员、文化交流）。

- **职业身份要真实**。不能仅是纸面——你的雇主必须能在被询问时给出一致的答复。
- **职业相关材料、邮箱、工作日程要齐备**——这是被询问时的"第一层故事"。
- **职业身份与事工身份在数字层完全隔离**：不同邮箱、不同设备、不同社交账号。
- 任何"按外教身份发的朋友圈"不要透露事工内容；任何"事工平台上的发言"不要透露雇主信息。

## 家庭与子女

- **配偶必须知情，并接受同等水平的设备 / 账号训练**。被约谈、被搜查时，对家属的提问往往先于对当事人。
- **不要把子女学校相关材料和事工资料放在同一台设备**。
- **教导子女对外不要说"爸爸 / 妈妈是宣教士"**——孩子在学校不经意的一句话，是被纪录的。建议给一个真实而中性的答复（例如"我爸爸是英语老师"——前提是这是真的）。
- **国际学校 / 双语学校** 的家长群是 OSINT 重点目标，谨慎使用。
- **应急联络人** 要在国内 + 海外各有一位，海外那位的电话号码要让配偶记得（不仅在手机里）。

## 同工互保——"如果今天我被带走，我手机上的什么会牵连到谁？"

这是事工团队**每个季度都应该一起做一次**的练习。

- **每位同工列出**：自己设备上有哪些信息会让其他同工 / 信徒受牵连。
- 然后**集中清理**那些信息：删除、迁移到加密存储、转为只在面对面聚会时携带的纸本。
- **同一份名册不能同时存在于 3 个以上同工的手机里**——任何一台被搜查都会暴露。
- 团队内**约定一个"如果某人 24 小时联系不上，我们应该做什么"的剧本**：
  - 谁负责联络家属？
  - 谁负责通知海外差派机构？
  - 谁负责安静地清理 / 撤掉公共可见的事工痕迹（公开页、聚会场所、车辆张贴等）？
  - 谁**不要**对外说话？
- 剧本以纸面备份给每位同工各保留一份（不在手机里）。

## 被传唤 / 被搜查 / 被驱逐时的预案

- **不要撒谎，但也不要主动多说**。
- **要求看证件、问清楚是什么程序**（约谈？传唤？刑拘？行政拘留？）——不同程序权利不同。
- **要求律师，能书面就书面**。不要在没有律师在场的情况下签任何文件。
- **不要在情绪中说出他人的名字**——这是事后回看里最常见的、最令人痛心的失误。
- **设备能关机就关机**，不只是锁屏。冷启动状态最强。
- 外籍人员被告知"限期离境"时——
  - 优先确保你**不带走**任何会牵连本地同工的资料。
  - 优先安排海外差派机构联络本地同工的"事后陪伴"。
  - 不要在过境时发任何朋友圈 / 推文 / 公开声明——出境之前任何声明都可能恶化留下的人的处境。

## 出走预案 / Go-Bag

外籍家庭应预先准备：

- 24 小时内可走的护照、文件、儿童证件、应急现金（多币种小额）、备用 SIM、已加密的关键资料 U 盘。
- 已和海外母会 / 差派机构对齐的"撤离决策点"（什么程度的事件就立即离境？）。
- 国内同工**不**进入这份预案——他们没有这个选项。把这一点想清楚，是这一类事工最沉重的伦理之一。

## 中国籍同工的额外考虑（**最重要**的一节）

外籍人员被驱逐之后，留下来的中国籍同工才是真正的高风险方。请额外准备：

- **不要把中国籍同工的姓名、身份证、户籍信息放在外籍人员的设备上**。一旦该设备被检查，整个网络一并暴露。
- **不要让中国籍同工在事工资料里使用真名**——化名 + 仅同工知道的对照表（纸本，存放在受信任的位置）。
- **中国籍核心同工应有自己的法律预案**：哪个律师、哪个家庭联络人、哪份保释 / 探视的资金来源——**事先**安排。
- **家属支持**：如果同工被拘留，家属（特别是孩子和老人）的生活、医疗、子女学籍是首要支持点，不是新闻发声。
- **教会群体不要在事件发生当天涌向当事人家中**——这会进一步标识相关人员。安静、分散、有节奏地支持。
- **海外发声**：是中国籍同工承担后果——不是发声者。**任何对外公开的内容、口径、时机，都应当由当事人本人 / 其家属、或被授权代表他们的差派机构决定**。

## 事件发生后：对外与不对外

- **第一波 24 小时**：**不**发朋友圈、**不**推特、**不**告诉非核心人员。先核实事实，先和家属对齐，先咨询律师与差派机构。
- **第一波要做的事**：通知差派机构、通知海外法律支援机构、和家属一起决定下一步。
- **媒体的诱惑很大**——海外华人圈、英文媒体常常希望迅速发稿。**这通常对留下的人不利**。
- **若决定公开**，应由家属 / 律师 / 差派机构主导，外籍同工只是配合。
- **不要在公开报道中写出未被拘留同工的姓名、单位、家乡**——他们是下一批可能被关注的人。

## 不要做的事

- **不**用号称"反追踪 / 净化 / 加速"的国产 APP——它们是问题来源。
- **不**在 WeChat / QQ 群发"代祷请求 + 真实姓名 + 病情 / 案情"——代祷是正当的，但带着真实姓名和情况群发，等于把当事人钉在数据库里。改用 Signal 小群或面对面祷告会。
- **不**在事工聚会场所共用 Wi-Fi 让每个人都连——一旦 BSSID 被关联，整组人就在同一时间出现在同一坐标上。
- **不**因为某项工具"听起来很硬核"就采用它。低调 + 一致 + 持续地做对的事，比偶尔做一次硬核的事重要得多。
- **不**把这份清单发到任何聊天群——你以为是关怀，对手把它当"这群人在讨论防侦查"的标识。请单独转发给真正需要的人。

## 今天就能做的事

- [ ] 团队下一次面对面会面时（**不在手机能听到的距离**）做一次"如果今天我被带走"的练习：每人写出自己手机上会牵连别人的内容，然后回去之后清理。
- [ ] 把所有事工通讯从微信迁出，至少给核心同工每人开一个 Signal。
- [ ] 把名册 / 奉献记录 / 培训材料从云端搬到加密容器（Cryptomator / VeraCrypt），并在团队中分散保存。
- [ ] 关闭手机 / 相机的照片 GPS 标签，停止把合影发到任何群里。
- [ ] 提前联系一位有刑事辩护 + 涉外业务经验的执业律师，事先建立联系——不要等到事情发生时再找。
- [ ] 与海外差派机构 / 母会的安全官（Security Officer）对齐"撤离决策点"。
- [ ] 在纸面写一份"如果我 24 小时联系不上"的同工剧本，每位同工各留一份。
- [ ] 把这份手册的链接私下转给真正需要的人——**不**转发到任何群里。

> **底线**：在中国大陆从事跨文化宣教 / 牧养事工的人，最重要的不是"自己安全"，而是"承担后果的人尽量少"。
>
> 三件事如果只能做三件：
> 1. **设备分层 + 名册分层**——你身上不应该有一份能点亮整个网络的清单。
> 2. **角色风险分层**——外籍人员在做决定时，永远把"留下来的人能不能承担"放在前面。
> 3. **预案、预案、预案**——预先安排律师、家属支援、海外联络、撤离决策点；不要等事情发生时再做。
>
> 信仰的层面我们不替你回答——那是你和你所信靠的位格之间的事。技术的层面，**沉默而稳定的纪律 > 公开而高调的姿态**。

## 资料来源与可寻求帮助的机构

- **ChinaAid（对华援助协会）**：长期处理中国大陆宗教自由案例，提供律师网络、家属支援、国际倡导。https://www.chinaaid.org/
- **Open Doors（敞开的门）**：国际基督教受迫害事工组织，每年发布 *World Watch List*。https://www.opendoors.org/
- **Voice of the Martyrs（殉道者之声）**：长期关注全球受迫害教会，有家属支援与法律协助渠道。https://www.persecution.com/
- **ChinaSource**：研究中国教会的英文研究与资讯机构，可帮助海外差派机构理解情况。https://www.chinasource.org/
- **Citizen Lab — 关于中国 APP 与监控的多份报告**：https://citizenlab.ca/
- **EFF — *Surveillance Self-Defense***：https://ssd.eff.org/
- **当地有跨境经验的执业律师** — 必须**事先**安排，不要等事情发生时找。
- **海外差派机构 / 母会的安全官（Security Officer）**——现代正规的差派机构都有 SO 角色，他们的工作就是这个。
