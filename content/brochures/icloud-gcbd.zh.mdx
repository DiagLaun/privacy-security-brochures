如果你用的是中国大陆 Apple ID（注册地为「中国大陆」），你的 iCloud 数据自 2018 年起由「云上贵州大数据产业发展有限公司」（GCBD）运营，存储在贵州境内的数据中心。这一安排由 Apple 自己在《政府信息请求》《iCloud 中国大陆运营商》等公开文件中说明。本篇说清楚它意味着什么、不意味着什么，以及普通人和高风险用户分别该怎么处理。

## 基本事实（可在 Apple 官网查证）

- 中国大陆 Apple ID 的 iCloud 数据由 GCBD 作为运营方，Apple 作为合作方共同管理。
- 数据存储在中国大陆境内，受中国大陆法律管辖；GCBD 在收到合法请求时按中国大陆法律配合。
- 加密密钥（包括用户加密密钥）也存储于中国境内。
- Apple 的 **「高级数据保护」（Advanced Data Protection）** 功能在中国大陆 Apple ID 上不可用——这是 iCloud 备份、iCloud 云盘、照片、笔记等大多数数据获得端到端加密的开关。
- 部分数据**始终**端到端加密，与是否启用「高级数据保护」无关，例如 iCloud 钥匙串、健康数据、Apple Pay 信息、屏幕使用时间等。

换句话说：**国行 Apple ID 的 iCloud 备份、照片、文件、邮件、笔记、提醒事项默认是 Apple/GCBD 可以解密的状态**，并依本地法律响应执法请求。

## 哪些数据通常会被同步上去

如果你没有专门关掉，国行 Apple ID 默认会同步：

- **iCloud 备份**：聊天记录、APP 数据、设置、相册元数据等的设备级备份
- **iCloud 照片图库**：所有相册、视频
- **iCloud 云盘**：「文件」APP 中的内容，包括第三方 APP 写入的文件
- **iCloud 邮件 / 通讯录 / 日历 / 提醒事项 / 备忘录**
- **Safari 浏览历史与书签**
- **设备查找**（位置）
- **iMessage 与 SMS** 的备份（不是端到端密钥，是 iCloud 备份里的副本）

iMessage 本身在传输过程是端到端加密的。但只要 **任意一端**（你或对方）启用了 iCloud 备份，备份里就会保存可解密的信息副本。

## 普通用户怎么做

如果你不是高风险人群，目标是把"日常会被陌生人滥用的隐私"管住：

- 进入「设置 → Apple ID → iCloud」，逐项检查每个功能是否真的需要同步。
- **关掉不需要的同步**：比如不一定要把全部照片放云端、不需要把所有 APP 都做 iCloud 备份。
- 改用 **本地加密备份**：把 iPhone 接电脑用 Finder/iTunes 做加密备份，加密后的备份文件再放到自己的硬盘里。
- 把真正敏感的内容（财务证明、身份证扫描件、合同、私密照片）从「文件」与「照片」里移走，放到一个端到端加密的网盘（Proton Drive、Tresorit 等）或本地加密容器。
- iCloud **钥匙串**可以保留——它在端到端加密范围内。

## 高风险用户怎么做

适用于：调查记者、维权律师、跨境工作者、政治敏感人群、家暴受害者、对身份保护有强需求的人。

- **真正敏感的工作不放在国行 Apple ID 上**。考虑：
  - 注册一个海外 Apple ID（注册地不是中国大陆），登录工作设备，用它的 iCloud 与高级数据保护。
  - 注意：双 Apple ID 切换有应用商店、Apple 服务可用性的影响；不同地区 Apple ID 的合规风险与你所在地法律相关，请自行评估。
- **iMessage 不要做 iCloud 备份**。iMessage 本身端到端，但 iCloud 备份会保留可解密副本。
  - 「设置 → Apple ID → iCloud → 信息」关闭。
  - 「设置 → Apple ID → iCloud → iCloud 备份」可整体关闭，改本地加密备份。
- **设备查找**：要不要打开因人而异——它能帮你找回手机，也是一个永远在云上知道你位置的服务。视威胁模型决定。
- **照片同步**：高风险用户基本应当关闭。手机相册里的人脸、地点元数据非常敏感。
- **企业/学校配置文件**：检查「设置 → 通用 → VPN 与设备管理」是否被装过陌生的描述文件或证书。
- 跨境出行前请同时阅读《[High-Risk Environments](/brochures/high-risk-environments)》。

## 今天就能做的事

- [ ] 打开「设置 → Apple ID → iCloud」，看一眼 **现在到底同步了哪些类目**。
- [ ] 关掉至少一个你其实不需要云端同步的类目（"文件"、"照片"、"备忘录"任选其一开始）。
- [ ] 把"信息"的 iCloud 同步关掉（高风险用户必做）。
- [ ] 把真正敏感的文件从「文件」APP 中移到本地或端到端加密网盘。
- [ ] 把"查找"的家庭分享、位置共享名单清理一下，移除已经不该看到你位置的人。

> **底线**：国行 Apple ID 不等于不安全，但它确实让 Apple 与 GCBD 在法律允许的范围内能解密大部分 iCloud 数据。把"日常云端便利"和"真正敏感的工作"分开，是这件事最重要的一步。
