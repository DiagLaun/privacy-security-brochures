「手机管家」「安全中心」「清理大师」这类应用在国产 Android 上几乎人手一个：有的是系统自带（华为手机管家、小米安全中心、OPPO/vivo 安全中心），有的是第三方（腾讯手机管家、360 手机卫士、猎豹清理大师等）。它们的功能定位是杀毒、清理、骚扰拦截、隐私管理。问题在于——为了"管理你的手机"，它们要的权限往往比真正需要的多得多。

## 它们通常在做什么

公开宣传的功能：

- 病毒扫描、APP 行为监控
- 内存清理、流量统计
- 骚扰电话与短信拦截
- 「权限管理」「隐私保护」「应用锁」
- 系统更新、补丁推送
- 「新闻资讯 / 头条 / 视频」推荐流（**注意**：很多管家把它当默认入口）

为了实现这些功能，常见会请求的权限：

- 读取已安装应用列表
- 读取通话记录、来电状态
- 读取短信内容
- 读取通讯录
- 读取系统通知
- 定位
- 读写"所有文件"的存储权限
- **「无障碍」服务**（Android Accessibility Service）
- **设备管理员**

最后两项尤其值得注意——「无障碍」相当于把整块屏幕上的内容、所有点击与文字输入都暴露给该 APP；「设备管理员」让该 APP 可以对设备执行强制锁定、擦除等动作。一旦授予，撤销也比普通权限麻烦。

## 默认开启的"用户体验改进"是什么

几乎所有国产手机管家/安全中心都会默认开启一项叫「用户体验改进计划」「加入产品改进」「数据贡献」之类的开关。它通常上传：

- 设备型号、系统版本、地区
- 已安装应用清单及版本
- 应用的崩溃与卡顿日志
- 部分"行为轨迹"——例如哪个功能用了多少次、什么时间用的
- 部分"性能数据"——CPU、内存、网络情况

不同厂商上传的范围不同，**请以你手机上的「隐私政策 / 个人信息收集清单」为准**，国产手机近两年的系统普遍都有一个详细到每一条的"个人信息共享清单"页。

## 风险与权衡

- **它们本身不一定恶意**，但聚合的权限与遥测面非常大。一旦该 APP 被攻破或被供应链滥用，泄露面也很大。
- 第三方手机管家在历史上多次被发现有"诱导授权""默认勾选个性化广告""频繁调起其他自家应用"等问题。
- 系统自带的安全中心通常做得更克制，但仍然默认开启了大量遥测与推送通道。
- "应用锁""隐私保险箱"功能本身可以用，但**密码就是这个 APP 知道**——不要把它当成端到端加密的保险柜。

## 普通用户怎么做

如果你只是想让手机别那么吵：

- **保留一个就够了**：系统自带的"安全中心 / 手机管家"通常已经够用，不需要再装第三方。
- **关闭"用户体验改进计划 / 加入数据贡献"**：在该 APP 的"设置 → 关于 / 隐私"里。
- **关闭"个性化广告 / 个性化推荐"**：在系统的"广告与隐私 / 个性化"里关掉广告 ID（部分系统支持重置广告 ID，每月重置一次更稳）。
- **关闭"新闻 / 头条 / 视频"推荐流**：你装的是安全中心，不是新闻 APP。
- **检查"无障碍权限"**：「设置 → 无障碍」看看哪些 APP 开了无障碍服务。除非真的需要（屏幕阅读、自动化），否则一律关闭。
- **检查"设备管理员"**：「设置 → 安全 → 设备管理员」，删除你已经不用的 APP。

## 高风险用户怎么做

- **不要用第三方手机管家**：能用系统自带就用系统自带，能不用就不用。
- **彻底关闭"用户体验改进 / 数据贡献"**，包括系统层面的相关开关（"加入华为用户体验改进计划""加入小米用户体验计划""帮助改进 ColorOS"等）。
- **不要把工作设备和私人设备共用**。一台手机授权给手机管家"无障碍 + 设备管理员"，这台手机就不能再被当作"安全设备"来处理敏感工作。
- **跨境前考虑刷机**。出行时用一台干净的、未登录国产账号的设备，详见 《[High-Risk Environments](/brochures/high-risk-environments)》。

## 今天就能做的事

- [ ] 打开你手机里的"安全中心 / 手机管家"，找到它的"设置 → 关于 / 隐私"，关掉**用户体验改进计划**。
- [ ] 系统设置 → 隐私 → "广告"，**关掉个性化广告**，并重置广告 ID。
- [ ] 系统设置 → 无障碍，**确认每一个开了无障碍权限的 APP 都是必要的**。
- [ ] 卸载至少一个你已经不用的第三方"清理 / 加速 / 杀毒" APP。
- [ ] 检查"通知访问"和"使用情况访问"权限列表。

> **底线**：手机管家不是不能用，但它要的权限远超它表面的功能；保留一个、关掉遥测、严格管"无障碍"和"设备管理员"，是最低成本的自保。
