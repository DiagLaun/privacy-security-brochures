「网络监控」在中国大陆是一个多层叠加的现实：从 ISP 层的深度包检测，到公共场所的实名 Wi-Fi、企业/校园网的代理证书、公共空间的视频监控（"天网""雪亮工程"等），都在不同维度上记录你的网络与物理活动。**本篇不讨论如何规避网络管制（如 GFW），那超出本手册定位、在中国大陆涉及法律风险，请咨询合资质律师**。本篇只解释这些层级是什么，并给出在合法范围内的日常自保建议。

## 监控发生在哪些层

理解监控，先要知道它分层：

1. **运营商网络层（ISP）**：所有非端到端加密的流量、以及加密流量的元数据（你访问了哪个域名、什么时候、用了多少流量）都会经过运营商的设备，部分由 DPI（深度包检测）系统持续分析。
2. **公共 Wi-Fi 层**：商场、地铁、餐厅、咖啡馆的"免费 Wi-Fi"普遍要求微信扫码登录、短信验证、或实名认证。日志会与你身份关联保存。
3. **企业 / 学校网络层**：很多单位的网络要求安装"根证书"或"安全客户端"才能上网。一旦安装，HTTPS 流量在该网络内部会被解密、检视、再加密——**对方可以看到你 HTTPS 内容**。
4. **应用层遥测**：你装的 APP（浏览器、地图、社交、外卖、电商）本身就会持续上传你的行为，与上面三层叠加。
5. **物理空间层**：城市公共空间的摄像头网络（"天网""雪亮工程"）和门禁/支付设备共同构成的物理"轨迹数据"，与网络数据可以在多个维度上对应。

任何一层单独看是合规的、有公开依据的；它们组合起来，就形成了"大数据监控"这个常被讨论的现象。

## HTTPS 到底保护了什么

HTTPS（端到端 TLS 加密）保护**内容**——你在网页上输入的密码、看的文章正文、聊的内容。

但它**不**完全保护**元数据**：

- 你访问了哪个域名（**SNI** 字段，传统 TLS 中是明文；ECH/Encrypted Client Hello 在很多 CDN 已支持但部署不齐全）
- 你访问的频率与流量大小（流量分析）
- 你的 IP（你这一端 + 服务端 IP）
- DNS 查询（除非开启 DoH / DoT，否则通常明文）

在公共/企业网络下，监控方掌握的"信息量"在**元数据 + 应用层数据 + 物理空间数据**叠加之后，已经远多于"看你聊了什么"。

## 公共 Wi-Fi 的真实风险

- **强制实名**：扫码登录会把"该手机号在这个时间段连接了这个商圈 AP"写入日志，留存周期一般以年计。
- **入口劫持 / 弹窗广告**：部分公共 AP 会向 HTTP 流量注入广告或脚本。
- **"假免费 Wi-Fi"**：不法分子搭建同名 AP 钓鱼，目标是劫持你访问的金融 APP。
- **DNS 劫持**：把你访问的合法域名解析到伪造 IP。

## 企业 / 学校网络的"根证书"是怎么回事

如果上网必须装"安全客户端"或"导入根证书"才行，意思是该网络在中间安装了一台 SSL 拦截设备（俗称 "SSL 解密 / 内网代理"）：

- 你访问 HTTPS 网站时，浏览器收到的不是真实站点证书，而是中间设备伪造的、由"刚装上的根证书"签发的证书。
- 因为根证书是你自愿装的，浏览器认它合法，**不会报错**。
- 中间设备得以解密、检视、记录全部 HTTPS 内容，再用真实证书重新和真站点通信。
- 一旦在这台设备上**做过个人事**——登录私人邮箱、查看私人聊天、登录银行——这些内容**已经通过明文路过该设备**。

**这是合法的企业管理手段**，但你应当假设：装了根证书的设备 = 不能做私人敏感操作的设备。

## 普通用户怎么做

- **优先使用蜂窝数据**做敏感操作（网银、医疗、私密聊天）。
- **不要随手连任何不需要密码的公共 Wi-Fi**。如果需要连，**关掉自动连接、关掉自动登录、用完手动断开**。
- **公共 Wi-Fi 上不开网银，不输支付密码，不登录主邮箱**。
- 在浏览器层启用 DoH（Chrome / Edge / Firefox 都支持），并选一个值得信赖的 DNS 提供方。
- 不在公司/学校设备上做私人敏感操作；不在这些设备的浏览器里"保存密码"。
- 把锁屏通知设为不显示具体内容——城市监控摄像头看不到你屏幕，但身边的人看得到。
- 不点"一键诊断网络""清理 DNS"等来源不明的工具——它们经常顺手装根证书。

## 高风险用户怎么做

- **工作机彻底不连公共 Wi-Fi**，跨城/跨境时只用专门的工作流量卡。
- **绝不在装了企业根证书的设备上**处理任何工作敏感内容。
- 流量分析对抗超出本篇范围；如果你的威胁模型确实要求，**找专业人员一对一咨询**，例如 Access Now 的 Digital Security Helpline。
- 阅读 《[High-Risk Environments](/brochures/high-risk-environments)》。

## 关于"翻墙"的边界声明

本手册不讨论如何绕过 GFW：

- 在中国大陆，未经批准的"翻墙"工具及相关行为存在明确的法律风险，不同地区与不同身份所承担的实际后果不同。
- 这是法律与个人决策问题，不是技术问题；本手册不替你做这个决策。
- 如确有合法的跨境业务、学术、合规研究需求，请走单位的合法专线 / VPN 申请途径。

## 今天就能做的事

- [ ] 关闭手机的"自动连接公共 Wi-Fi"。
- [ ] 在浏览器里**启用 DoH**（设置中搜索"安全 DNS"）。
- [ ] 检查电脑的"受信任的根证书"列表，删除来源不明、自己也想不起来为什么装的根证书。
- [ ] 把"在公司/学校电脑上做的私人事"清单写下来，逐项搬到自己的私人设备上去做。
- [ ] 把锁屏通知改为"隐藏内容"。

> **底线**：HTTPS、DoH、不连陌生 Wi-Fi、不在装了企业根证书的设备上做私事——这四件事覆盖了普通用户面对网络监控的大部分自保需求；剩下的属于威胁建模，每个人答案不同。
