「装哪一款加密通讯 APP」并没有标准答案。它取决于你的网络条件、对方愿不愿意装新 APP、你最在意的是「内容加密」还是「连谁、什么时候说话」（也就是元数据），以及——很现实地——这款 APP 在你所处的网络下是否真的能连上。

这篇手册比较四款在中文用户群里被提到最多的、面向「私密通讯」的 APP：**Signal、Threema、Delta Chat、Zangi**。不讨论微信、QQ、Telegram，因为它们要么不是端到端加密，要么默认不开端到端加密，性质和上面四款不同。

> **本手册不指导任何规避网络管制的做法。**「该不该这么做」属于法律 / 个人判断，请按所在地法律自行评估。

## 先给结论

- **从纯安全角度**：Signal 是天花板——协议最强、审计最深、元数据最少。
- **代价**：Signal 在中国大陆默认不可达，必须先有一层可用的网络中转；并且注册必须用手机号。
- 如果你不能 / 不愿做这一层网络中转：
  1. **首选 Threema**——通过审计、不需手机号、多数时间在大陆可不经 VPN 访问。
  2. **以 Delta Chat 作为备用**——架构最特别，本质上是带 OpenPGP 加密的邮件客户端。
  3. **不建议 Zangi**——闭源、无独立审计、加密细节未公开。

## 四者对比

| 项目 | **Signal** | Threema | Delta Chat | Zangi |
|---|---|---|---|---|
| 公司所在地 | 美国（Signal 基金会，非营利） | 瑞士 | 德国 / 开源社区 | 亚美尼亚 → 美国 |
| 费用 | 免费（靠捐款） | 一次性约 ~$5 | 免费 | 免费，含付费版 |
| 是否开源 | **客户端 + 服务端全部开源** | 客户端开源（2020 起）；服务端闭源 | 完全开源 | **闭源** |
| 是否有独立安全审计 | **最多、最深入**（Signal 协议被 WhatsApp、Messenger 等也采用） | 有（Cure53 等多次） | Autocrypt 协议已审计；APP 由社区审阅 | **没有公开审计** |
| 端到端加密协议 | **Signal Protocol（Double Ratchet）+ 前向保密 + 后向恢复** | NaCl / Curve25519 | OpenPGP（Autocrypt） | 厂商自研，细节未公开 |
| 注册需要的身份 | **手机号（必填）**；新版支持"用户名"，可不向联系人暴露手机号，但 Signal 自身仍持有 | 一个随机的 Threema ID（不需手机号、不需邮箱） | 一个邮箱地址 | 手机号 |
| 服务端 | Signal 自营（美国），sealed sender + 私密联系人发现 | Threema 自营（瑞士） | 由你自己选择的邮箱服务商（联邦式） | Zangi 自营 |
| 元数据暴露 | **公开法庭记录显示：传票能拿到的几乎只有"账号是否存在"+"最后连接时间戳"** | 很低，公开透明度报告 | 取决于你用的邮箱服务商 | 宣传"无服务器"，实际有路由基础设施 |
| 群聊 / 语音 / 视频 / 文件 | 全部支持，含 50 人群组通话、屏幕共享 | 全部支持 | 文字 / 文件支持；语音视频较弱 | 全部支持 |
| 在中国大陆的可达性*（变化频繁）* | **默认不可达**，需要 VPN / Tor / 代理 | 多数时间可不经 VPN 访问，曾被屏蔽 | 取决于你用的邮箱服务商 | 当前据反馈可达 |

## 各 APP 实质差异

### Signal

- 客户端 + 服务端**全部开源**；Signal 协议被 Cure53 等多次审计，并被 WhatsApp、Skype、Messenger 等主流 APP 直接采用。
- **前向保密 + 后向恢复**：即使某次密钥泄露，过往与未来的对话仍然安全。
- **元数据极少**：公开的法庭文件显示，美国政府向 Signal 索要数据时，能拿到的只有"账号是否存在 + 最后一次连接时间"。
- 短板：
  - **必须用手机号注册**。在中国大陆使用国内 SIM 注册，会把账号绑到实名身份；如果威胁模型不允许，需要使用境外 SIM 或可信境外虚拟号（很多虚拟号要求实名，且不一定能稳定收 SMS）。
  - **国内默认不可达**，需要先有一层可用的网络中转。这一层本身就是一项可被观察的行为。

### Threema

- 在四款里最像 WhatsApp 的"完整体验"，但注册用一个**随机 ID**（不是手机号、不是邮箱），可在不向联系人暴露真实号码的前提下使用。
- 元数据记录极少，瑞士公司、瑞士隐私法管辖，Cure53 等多次审计。
- 一次性付费（约 5 美元）反而是个"反垃圾骚扰"的天然过滤器。
- 短板：只有一个中心服务（瑞士），一旦被屏蔽就整个不能用，APP 内部没有抗审查层。
- **对"在中国大陆希望不依赖 VPN 就能用"的需求来说，Threema 是首选**。

### Delta Chat

- 架构最有意思的一款：本质上是普通的 IMAP / SMTP 邮件客户端，**自动**给邮件加上 OpenPGP（Autocrypt）端到端加密。
- **没有"Delta Chat 服务器"——你的账号就是你的邮箱**：
  - 用**境外邮箱**（mailbox.org、posteo.de 等付费隐私邮箱，需先确认在你网络下可达）：可获得相当强的端到端加密，且建立在难以整体屏蔽的邮件协议之上。
  - 用**国行邮箱**（163、QQ 邮箱等）：正文仍加密，但邮箱服务商可看到"你和谁通过 Delta Chat 在何时通信"，并可按要求处置账号。
- 短板：语音 / 视频功能弱于 Signal / Threema；双方都必须装 Delta Chat（或其他兼容 OpenPGP 的邮件客户端）；密钥信任模型是"首次接触即信任"（TOFU），不像 Signal 那样有基于安全号码的二次验证。

### Zangi

- 营销重点放在"无服务器、端到端、抗审查"。
- 实际情况：**闭源、没有公开的独立安全审计、加密协议未公开记录**。
- 这不等于"一定不安全"，但**意味着安全宣称无法验证**。
- 适用：如果你只把它用于"和家人语音通话、内容本身不敏感"，没问题。
- 不适用：任何"对方就算翻不出来、我也想保证内容安全"的场景，不应把信任放在一个无法验证宣称的 APP 上。

## 普通用户怎么选

「普通用户」指的是：你不在新闻 / 法律 / 维权 / 跨境敏感工作的高风险类目里，只是希望日常聊天不要被随便看到。

- **最低成本方案**：装 Threema，把 ID 通过电话或当面告诉真正在意你隐私的家人朋友。一次性付费即可，省去后续骚扰。
- **不愿付费 / 想跨平台**：装 Delta Chat，配合一个**付费的境外隐私邮箱**（mailbox.org、posteo.de、tutanota 等，先确认在你网络下能正常收发邮件）。
- **不要把 Zangi 当成"装了就安全"**。

> 普通用户最容易踩的坑不是"选错 APP"，而是"对方一直在用微信，所以你也只用微信"。**至少为最敏感的几位联系人开一条第二渠道**——出事时它会救你。

## 高风险用户怎么选

适用于：调查记者、维权律师、参与敏感案件的当事人、政治敏感人群、家暴/跟踪受害者，以及代表 NGO / 宗教 / 少数群体进入高风险地区的人。详见手册的「高风险环境下的应急处置」一篇。

- **首选仍然是 Signal**——协议、审计、元数据三项都明显领先；用户名功能让你不必把手机号交给联系人。
  - 注册手机号要慎重选：不要用国内常用号；最稳妥是已有的境外号或一次性 eSIM。
  - 与最敏感的联系人**亲自核对安全号码**。
  - 默认开"消失消息"。
- **Threema / Delta 作为 Signal 不可达时的退路**，不作为生命安全级对话的主通道。
- **联系人头像和昵称不要写真名 / 真单位**。Signal、Threema 的联系人列表本身在设备被检查时即可暴露关系网。
- **跨境前先评估当地法律**对相关 APP 的态度——"持有这个 APP 本身就是问题"的地方真实存在；过境时建议先卸载、必要时再重装。
- **任何一台设备都不能同时是"主力机 + 高风险通讯工具"**。

## 几个必须说清楚的边界

- **网络管制下的可达性非常不稳定**：本月能用的下个月不一定能用。**任何工作流都不要做成"只有这一款 APP 在用"**——和对方提前约好备用渠道。
- **在中国大陆使用任何境外端到端加密通讯 APP 本身就是一种可被观察的行为**。「该不该用」与「技术上能不能用」是两个独立问题，前者属于法律 / 个人判断，每个人答案不同，本手册不替你回答。
- **端点失守胜过加密本身**：手机一旦被植入恶意软件，再强的协议也救不了你。设备本身的安全卫生是这一切的前提。参考：「鸿蒙 OS 与澎湃 OS 隐私设置」「输入法监控」「手机管家」三篇。
- **四款都需要对方装**。"群体采纳"通常是真正的瓶颈，比技术好坏更重要。
- **本手册讨论的是"端到端加密通讯 APP 之间的差异"**，不讨论如何让被屏蔽的 APP 可达。请按所在地法律自行评估并决定是否使用某项工具。

## 今天就能做的事

- [ ] 列出你最敏感的 3 位联系人，和他们约一条**不在微信 / SMS 上**的第二渠道。
- [ ] 普通用户：装 Threema 或 Delta Chat（任选其一），把 ID / 邮箱通过电话或当面告诉对方。
- [ ] 高风险用户：在 Signal 可达时把它作为主通道；和最敏感的联系人亲自核对安全号码、默认开消失消息；同时把 Threema 装好作为退路。
- [ ] 锁屏通知改为"隐藏内容"——再强的加密 APP 也挡不住肩后偷瞄锁屏。
- [ ] 把这篇手册转给你需要联系的人。**端到端加密的另一端，必须有人。**

> **底线**：从纯技术看，Signal 是天花板；不能 / 不愿做网络中转时，Threema 是最稳妥的退路；Delta Chat 是最适合在意元数据并愿意配置邮箱的人；Zangi 在做不到验证安全宣称之前不要用在重要场景。无论选哪一款，**都不能替代设备本身的安全卫生 + 备用通道 + 不在敏感渠道交换敏感事**。
