> **本手册不指导任何规避网络管制 / 规避合法侦查的做法**。
>
> 它面向**已经具备**多平台刷机、装系统、加密、自托管基础设施能力的事工技术同工——所以不重复教学，只讲**操作纪律、法律边界、人际边界、继任计划**。

技术同工是教会群体里风险最集中的一类人。你既不是带着职业掩护的外籍人员，也不是只承担"被牧养"风险的普通信徒；你是**力量倍增器**——一个人的能力为整个网络托底，相应地，**一个人倒下，整张网都会被点亮**。

请把下面三件事先在脑子里分开：

1. **你的技术能力**——你能做什么。
2. **你的可见性**——别人能看到你做什么。
3. **你被牵连的人数**——你掌握的钥匙、密码、文档对应多少人和家庭。

**真正的风险不是"我不会做"，而是"我做了之后留下了什么痕迹给谁看见，以及如果今天我倒下，多少人因此暴露"。**

## 第一原则：力量倍增器问题

技术同工最容易掉进的陷阱：

- 一个人维护着 30 位同工的密码管理器主密钥；
- 一个人知道事工域名 / VPS / 自托管服务的所有 root 凭证；
- 一个人帮 50 位信徒做了"OS 加固 + 安全套装"；
- 一个人是所有人的"技术问答群群主"。

只要这个人的设备 / 账号 / 通讯录任意一项被取得，**整个网络在同一秒钟被点亮**。

应对原则：

- **不做唯一知道的人**：所有关键凭证、所有自托管服务的访问权限至少 2 人持有副本；用真正的密钥分割（Shamir's Secret Sharing / Vault 之类的）做托管，纸本封存在不同地理位置。
- **不做唯一会做的人**：你培训过的同工里，至少要有 1 位能在 24 小时内接手你的角色——技术接班人和"如果我被带走"剧本同样重要。
- **不做唯一可见的人**：所有公开角色都用群体身份（"技术组"），不要让自己的个人身份和这个群体的对外形象绑死。

## 法律层面：技术行为本身的可追责性

这一节请**严肃对待**——技术同工和普通信徒在法律风险上是两个量级。下列条款在过去多个判例中曾被适用，并不是危言耸听。**所有具体决定请咨询有跨境 / 网络刑事经验的执业律师**，本手册不替你判断。

- **刑法第 285 条 / 285 条之三 / 286 条**——非法侵入、非法控制、非法获取计算机信息系统数据、破坏计算机信息系统。涉及绕过厂商锁、绕过审查、获取他人系统访问权时被适用过。
- **刑法第 287 条之二（帮信罪）**——为他人犯罪提供互联网接入、服务器托管、网络存储、通讯传输等技术支持。**这是过去几年判例增长最快的罪名之一**，门槛比你想象的低。
- **刑法第 225 条（非法经营罪）**——多起"私自搭建 / 出售 VPN"案件以此罪名追诉，无论是否盈利。
- **网络安全法 / 数据安全法 / 个人信息保护法**——涉及跨境数据传输、存储、提供工具时的合规义务。
- **国家安全法 / 反间谍法**——条款宽泛，对"涉外背景 + 技术能力"组合的敏感度高。

含义：

- **你"会"刷机、会自托管、会架设代理，并不等于你应该为别人这样做**。"为别人做"的那一刻，性质从"个人使用"变成"提供服务"——后者的法律后果质变。
- **不为非教会成员提供技术服务**。陌生人来找你帮忙"翻墙 / 装某个东西"，对方可能是钓鱼。
- **不接受任何形式的报酬**——一旦有报酬，最低限度的"非营利"框架也没了。
- **不批量化**——给一个家人帮忙刷一台机器，和"我手上有 50 张同样的 SD 卡待装系统"——是两件不同性质的事。

## 个人设备——既然有能力，就把每件事做对

技术同工**没有借口**像普通用户那样将就。请按这个标准要求自己：

- **主力机：GrapheneOS（Pixel）+ 海外 Apple ID iPhone（次选）**——你既然能装，就装对的那一台。
- **工作站全盘加密**：Linux LUKS、macOS FileVault、Windows BitLocker——**所有**机器、**所有**外接盘。
- **登录口令长度 ≥ 24，全 PIN 不行**。开机 / 解锁口令必须高熵。
- **生物识别只在低风险场景**——出门、过境、会被询问的场合，**改回口令**。
- **休眠 ≠ 关机**。任何离开身体的设备都应是关机状态，不是合盖。
- **二步验证全部硬件密钥**——YubiKey 5 / Titan 至少 2 把（一主一备份），不放任何短信 2FA。
- **密码管理器**：Bitwarden（自托管 vaultwarden 也行）/ KeePassXC，主密钥从不打字，从硬件密钥派生或 PIN+硬件解锁。
- **隔离工作流**：Qubes OS 是技术同工最值得花学习时间的系统——不同信任域物理隔离 VM。
- **网络层**：自己用什么是个人事；**不要把"自己用"和"为他人提供"混在一台机器、一份配置里**。

## 工作站 / 服务器 / 自托管基础设施

如果你为事工维护任何长期运行的服务（站点、文件服务器、邮件、聊天）：

- **不在家庭网络上跑**。家用 IP 一旦暴露 = 你的住址暴露。
- **境外 VPS 的支付不要用绑定真实身份的卡**——用海外业务伙伴 / 母会托管，或可信的第三方法律实体。本地法律下"以个人名义租境外服务器"在某些罪名构成上是被算入加重情节的。
- **域名注册不用真名**——用法律实体或注册商的 Privacy Service。
- **服务器配置走 IaC（Terraform / Ansible）**，不在 SSH 里手工调整。配置都在 Git 里——**Git 仓库本身要加密 / 私有 / 离岸**。
- **日志最小化**：关 access log，关 IP 留存，关一切非必要 telemetry。
- **没有"调试模式"长开**——调试结束立即关。
- **完整的死人开关（dead-man's switch）**：如果你 7 天没签到，关键服务自动停机或转交副本持有者；密钥按预设流程销毁或公开（按你和你团队的判断）。
- **离线灾备**：所有运行配置 + 数据加密备份到至少两个不同地理位置 / 不同管辖区。

## 硬件 / 软件采购

这是技术同工最常被忽略的暴露面：

- **不在同一个淘宝 / 京东账号下批量买"刷机相关"商品**——Pixel 一台 + USB OTG 一根 + microSD 一组 + USB-C 改机线一根——单独看正常，组合在一个账号下就是关键词。
- **不在同一个支付宝账号下集中购买"安全相关"硬件**——YubiKey、固定数量的 SIM 卡、加密 U 盘、电视盒子。
- **大宗采购通过海外渠道 + 物理代购**，分批到货，不集中到一个收件人地址。
- **不"为同工统一发货"**——每位同工自己采购自己的硬件；你只提供选购清单和教学。
- **GitHub / Codeberg 账号**——不要让"实名 GitHub" + "OPSEC 项目 stars" 出现在同一个账号上。"星标"也是元数据。
- **apt / brew / pip / npm 镜像**——使用海外原始源时确保你的网络出口本身是干净的；使用国内镜像时清楚每条请求都被运营商记录。

## 公开痕迹

技术人最大的虚荣——和最大的风险——通常是公开痕迹。

- **GitHub / GitLab 实名账号**不要参与任何能被解读为"规避审查 / 政治敏感"的仓库——不 Fork、不 Star、不评论、不 Issue。
- **博客 / 知乎 / 微信公众号 / X / Mastodon**全部分开管理——其中只有一条对应你的真实身份。
- **会议演讲 / 公开培训**不要谈具体的事工场景。即便讲安全话题，只用通用术语。
- **简历 / LinkedIn**上**不**出现教会、宣教、机构关键词，包括拼音首字母缩写。
- **照片 EXIF / 社交平台位置标签**全关。
- **OPSEC 自我检查清单**：把你的真实姓名 / 手机号 / 邮箱拿到 Google、Bing、必应、百度搜一遍，每月一次。看你已经留下了什么。

## 与受助者的边界

最容易出问题的是关系，不是技术：

- **不接收来自陌生人 / 新人的"教我装这个"请求**——验证 ≥ 3 个月共同事奉、≥ 2 位核心同工担保，再考虑。社工攻击的首选入口是"谦虚求教"的姿态。
- **不在群里**做技术答疑——任何群（含微信、Telegram、Signal 大群、Matrix 大房）都不可控。1:1 加密对话，或面对面。
- **不存"客户名单"**——你帮谁加固过设备、装过什么——**不**记录在任何介质上。如果非要追踪，用化名 + 单向哈希。
- **不留后门**——绝对不要在任何你帮别人加固的机器上留 SSH 公钥、远程管理通道、自启动脚本。"我帮你修过" ≠ "我永远能登录"。这是你的法律责任分界线。
- **不替别人保管证据 / 影像 / 案卷**——这是律师的工作，不是技术同工的工作。
- **教完即走**：教学的目标是让对方独立，不是让对方依赖你。

## 文档与培训材料的安全

你写下来教别人的文档，本身就是一份证据。

- **培训材料不挂名**——写法上避免使用任何能定位到你或事工的术语。
- **写给本群体看的内部文档**——加密容器（VeraCrypt / Cryptomator），或自托管 Cryptpad。
- **公开发表的安全教学**——只在中立平台，使用与本群体无关的笔名，并避免引用本群体的具体场景。
- **PDF 的元数据**清空（作者、修改者、机器名）。
- **截图的元数据 / 内容**：截图前关闭所有同工真实姓名、群名、个人信息——一张技术演示截图里看到一个"主日小组"群名，就是关键证据。
- **训练 / 演示视频**：尽量不录；必须录的，只在加密容器里保存、用完即销毁。

## 设备被搜查时

技术同工的设备被搜查时，所获取的信息量远超一般同工。预案：

- **生物识别在路上一律关闭**。这一条对所有人重要，对技术同工是底线。
- **冷启动 = 关机**。任何离开你身体的设备应是关机状态。
- **加密容器不挂载**——VeraCrypt 容器在不挂载时是无法识别的随机数据；挂载状态下被取得就基本暴露。
- **浏览器历史 / 命令历史 / SSH known_hosts**定期清理，或使用临时 shell（zsh + `HISTFILE=/dev/null` 模式）。
- **你的工作站如果只能加密，不能有"无痕模式"**——没有合理可解释的工作模式，反倒可疑。考虑双系统：一个"日常"系统（合理可见），一个加密分区或加密容器里的"工作"环境。
- **不要试图临场删除 / 销毁**——刑法上"销毁证据"是独立罪名，会被认为坐实"知道自己在做敏感事"。
- **保持沉默 / 要求律师**——这一句对技术同工尤其重要，因为对方只要问对一两个问题，你的回答就足以串起整张图。

## 继任计划：如果今天我被带走

技术同工被带走，整个事工的技术依赖链一起断。预案必须**早于事件**做：

- **凭证副本**：所有关键凭证 ≥ 2 人持有，使用 Shamir 分割存储；纸本封存。
- **运行手册**：你维护的每项服务，写一份"如何接手"的步骤手册（**不**写在你的工作站上，写在加密分发给副本持有者的包里）。
- **域名 / VPS 持有者**：不全部挂在你个人名下；和差派机构 / 海外法律实体共持。
- **接班人**：至少 1 位你训练过、能立刻接手的副手，最好是物理上不与你共同出现的人（不在同城、不在同一聚会场所）。
- **死人开关**：如果你 7 / 14 天未签到，关键服务自动停机、关键凭证自动按预设流程处理。
- **告知配偶 / 家人 / 律师**：你被带走时，他们应该联系谁、按什么顺序、说什么 / 不说什么。

## 自我关顾

技术同工承担的精神压力被严重低估。

- **不要独自承担所有事工技术问题**——即使你能。这是力量倍增器问题的另一面。
- **每周至少 1 天完全离开终端**——连续作息和持续可达对长期运营是反作用的。
- **找一位**可信的牧者 / 辅导员**倾谈**——不是教会内的，最好在你的事工网络之外。
- **和配偶 / 家人讲清楚**你在做什么、风险在哪——他们必须知情，否则在出事时他们会成为最先被询问、最容易出错的人。
- **承认极限**：如果你出现持续焦虑、失眠、过度警觉、抑郁——停下来。技术同工"耗到爆"的真实案例比被带走的更多。

## 不要做的事

- **不要因为"我会"就替每个人做**——你不是义务客服，你是有限的人。
- **不要把"硬核安全爱好者"和"事工技术同工"两个身份合在一个公开账号上**。
- **不要参与任何与本事工无关的"敏感技术"项目**——绕审查工具、隐私币转账、灰产去识别——这些与你**事工本身**无关，但出事时会被打包追诉。
- **不要在朋友圈 / 推上展示你的设备 / 工作环境**——一张键盘照片可能暴露 OS、桌面、终端历史。
- **不要把这份手册转发到任何同工群**。和「跨文化事工与本土牧养的安全注意事项」一篇相同的理由——它是关怀工具，但群发会变成定位标识。需要的人，私下发。

## 今天就能做的事

- [ ] 列出你掌握的全部凭证 / 密钥 / 服务清单；其中**至少 ≥ 1 项**今天就开始做副本持有 / 密钥分割。
- [ ] 列出你"独家会做的事"清单；选一项今天就开始训练接班人。
- [ ] 把你的实名 GitHub / 博客 / 社交账号过一遍——清掉所有指向事工 / 安全 / OPSEC 的痕迹。
- [ ] 检查你的硬件采购账号：过去 12 个月有没有"集中、批量、可疑组合"的购物记录。
- [ ] 设置一个 7 天死人开关（最简版本：cron + 加密邮件）。
- [ ] 和配偶 / 家人 / 律师约一次面谈，把"如果某天我联系不上"这件事说清楚。
- [ ] 给自己安排一个"每周完全离开终端"的固定时间。

> **底线**：技术同工的工作是把一群人的安全水位整体抬高，**而不是把所有人的钥匙握在你一个人手里**。
>
> 三件事如果只能做三件：
> 1. **不做唯一知道的人 / 唯一会做的人 / 唯一可见的人**——副本、接班人、群体身份。
> 2. **不替你不认识的人做事**——技术能力是恩赐，不是义务客服；**不为非核心成员提供任何技术服务**是法律安全的硬底线。
> 3. **预先做好继任和死人开关**——你的目标不是"永远不出事"，而是"出事时网络不会跟着塌"。
>
> 信仰的层面不替你回答——技术同工承担的孤独感和重量，往往比牧者还重。请记得：**你不是这张网的源头，你只是托住网的一只手**。这只手必要时是可以放下的。
